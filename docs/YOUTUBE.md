## Description

```
TapFlow turns every live DreamDEX Event Contract into a one-tap UP or DOWN call on Somnia Shannon, and makes the best tappers followable: when a leader taps, a follower's order is placed IN THE SAME BLOCK, by the chain itself. No keeper, no relayer, no next-block lag.

Everything in this video is real. Every number is read live from Somnia Shannon, and every transaction happened while the camera was rolling:

• a wallet connects, funds a capped session wallet with two real transactions, and taps — filled on the live on-chain order book, with the hash on screen
• a leader tap is broadcast through a Router contract, and Somnia's reactivity precompile invokes our CopyHandler inside that same block, which places the follower's order through a capped MirrorVault
• the mirror is shown landing in block 485621955, then opened on the Shannon explorer: status Success, method onEvent, sent FROM the contract. No externally owned account signed it.
• the same flow in Telegram: one command places a real immediate-or-cancel order from a chat, and the reply carries the fill and its transaction
```
